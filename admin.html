Only the GitHub account jayeshmark, with the verified email jayeshmarathe2000jm@gmail.com, can log in here. Anyone else sees only this login form, and gets no playbook data.

How it works, honestly: this page has no server and no password of its own. You paste a GitHub Personal Access Token you create yourself at github.com/settings/tokens, with Contents read and write for this one repo only. The token is stored only in your browser, it is sent only to api.github.com to check who you are and to save playbooks.json, it is never sent to this site's server, and it is never shown in chat. If you do not have a token yet, create one first, then come back here. Do not paste your token anywhere else, and do not send it to anyone in chat.
